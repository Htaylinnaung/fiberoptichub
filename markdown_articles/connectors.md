<h2>၁။ နိဒါန်း</h2>
<p>
    Fiber Optic Connectors တွေဟာ Cable များကို Switch, Patch Panel နဲ့ တိုင်းတာရေး ကိရိယာတွေမှာ လွယ်ကူစွာ ချိတ်ဆက်/ဖြုတ်ယူနိုင်အောင် ပြုလုပ်ထားခြင်း ဖြစ်ပါတယ်။
</p>

<h2>၂။ Key Specifications</h2>
<ul>
    <li><strong>LC Connector:</strong> Ferrule size 1.25 mm ရှိပြီး SFP Modules များတွင် သုံးသည်။</li>
    <li><strong>Insertion Loss:</strong> Standard Loss သည် ≤ 0.3 dB ရှိရပါမည်။</li>
</ul>
