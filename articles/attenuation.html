Fiber Optic Attenuation

Fiber Optic Basics • Beginner • ⏱️ 3 min read
Published: 2026-08-29

Fiber Optic Attenuation ဆိုတာဘာလဲ?

Fiber Optic Attenuation ဆိုတာ Fiber Optic Cable ထဲမှာ Light Signal ဖြတ်သန်းသွားတဲ့အခါ Signal Power လျော့နည်းသွားခြင်းကို ဆိုလိုပါတယ်။

Fiber Link တစ်ခုမှာ Transmitter ကနေ ပေးပို့လိုက်တဲ့ Optical Signal ဟာ Fiber အတွင်း အကွာအဝေးတစ်လျှောက် ဖြတ်သန်းသွားတဲ့အခါ Optical Power တဖြည်းဖြည်း လျော့နည်းလာပါတယ်။

💡 အလွယ်ဆုံးမှတ်ရန်

Attenuation = Signal Power လျော့နည်းခြင်း

Fiber ကြာလေ Loss ဖြစ်နိုင်ခြေ ပိုများလေ ဖြစ်ပါတယ်။

Attenuation ကို ဘာနဲ့တိုင်းတာသလဲ?

Fiber Optic Attenuation ကို ပုံမှန်အားဖြင့် dB သို့မဟုတ် dB/km နဲ့ ဖော်ပြပါတယ်။

dB က Fiber Link တစ်ခုမှာ ဖြစ်ပေါ်တဲ့ Optical Loss ကို ဖော်ပြနိုင်ပါတယ်။

dB/km က Fiber တစ်ကီလိုမီတာ အကွာအဝေးအတွင်းမှာ ပျမ်းမျှ Loss ဘယ်လောက်ရှိသလဲဆိုတာ ဖော်ပြတဲ့ Unit ဖြစ်ပါတယ်။

📌 မှတ်ထားရန်

dB = Total Loss ကို ဖော်ပြနိုင်

dB/km = Fiber တစ်ကီလိုမီတာအလိုက် Attenuation ကို ဖော်ပြနိုင်

Fiber Attenuation ဖြစ်စေတဲ့ အဓိကအကြောင်းရင်းများ

Fiber Optic မှာ Signal Power လျော့နည်းစေတဲ့ အဓိကအကြောင်းရင်းတွေ အများကြီးရှိပါတယ်။

  • Absorption
    Fiber Material က Light Energy အချို့ကို စုပ်ယူသွားခြင်း ဖြစ်ပါတယ်။
  • Rayleigh Scattering
    Fiber အတွင်းမှာ ဖြစ်ပေါ်တဲ့ Microscopic Scattering ကြောင့် Light Power အချို့ ဆုံးရှုံးသွားခြင်း ဖြစ်ပါတယ်။
  • Bending Loss
    Fiber ကို အလွန်အကျွံကွေးခြင်းကြောင့် Light Signal အချို့ Core အပြင်ဘက်ကို ထွက်သွားနိုင်ပြီး Loss ဖြစ်လာနိုင်ပါတယ်။
  • Connector Loss
    Connector တွေကို မှန်ကန်စွာမတပ်ဆင်ထားခြင်း၊ Connector End Face ညစ်ပတ်ခြင်းတို့ကြောင့် Loss ဖြစ်နိုင်ပါတယ်။
  • Splice Loss
    Fiber နှစ်ချောင်းကို Splicing ပြုလုပ်တဲ့အခါ Splice Quality မကောင်းရင် Loss တိုးလာနိုင်ပါတယ်။

1. Absorption Loss

Absorption ဆိုတာ Fiber Material ထဲမှာရှိတဲ့ အချို့သော Material သို့မဟုတ် Impurities တွေက Light Energy ကို စုပ်ယူခြင်း ဖြစ်ပါတယ်။

ဒီလိုဖြစ်တဲ့အခါ Light Signal ရဲ့ Power တဖြည်းဖြည်း လျော့နည်းလာပါတယ်။

2. Rayleigh Scattering

Fiber Glass ထဲမှာ အလွန်သေးငယ်တဲ့ Refractive Index Variations ရှိနိုင်ပါတယ်။

Light Signal က ဒီလို microscopic variations တွေနဲ့ interaction ဖြစ်တဲ့အခါ Light အချို့က မူလ Direction ကနေ Scatter ဖြစ်သွားနိုင်ပါတယ်။

ဒီဖြစ်စဉ်ကို Rayleigh Scattering လို့ခေါ်ပါတယ်။

3. Bending Loss

Fiber Cable ကို သတ်မှတ်ထားတဲ့ Minimum Bend Radius ထက် ပိုမိုကွေးလိုက်တဲ့အခါ Light Signal အချို့ Core အတွင်းမှာ မထိန်းနိုင်တော့ဘဲ Loss ဖြစ်နိုင်ပါတယ်။

Bending Loss ကို အဓိကအားဖြင့် Macrobending နဲ့ Microbending ဆိုပြီး လေ့လာနိုင်ပါတယ်။

Connector နဲ့ Splice ကြောင့် ဖြစ်တဲ့ Loss

Fiber Link တစ်ခုမှာ Fiber ကိုယ်တိုင်ကြောင့်သာမက Connector နဲ့ Splice Point တွေကြောင့်လည်း Optical Loss ဖြစ်နိုင်ပါတယ်။

Loss Source ဖြစ်နိုင်တဲ့အကြောင်းရင်း
Connector Loss Dirty End Face / Misalignment
Splice Loss Poor Fusion Splice / Fiber Misalignment
Bending Loss Excessive Fiber Bend
Fiber Attenuation Absorption / Scattering

Wavelength နဲ့ Attenuation

Fiber Optic Attenuation ဟာ Wavelength အလိုက်လည်း ကွာခြားနိုင်ပါတယ်။

Telecom Network တွေမှာ 1310 nm၊ 1490 nm၊ 1550 nm စတဲ့ Wavelength တွေကို အသုံးပြုကြပါတယ်။

အသုံးပြုတဲ့ Fiber Type နဲ့ Wavelength ပေါ်မူတည်ပြီး Fiber ရဲ့ Attenuation Characteristics က ကွာခြားနိုင်ပါတယ်။

Attenuation ကို ဘာလို့စမ်းသပ်တိုင်းတာမလဲ?

Fiber Link ရဲ့ Optical Loss ကို စစ်ဆေးတဲ့အခါ Optical Power Meter (OPM) နဲ့ Optical Light Source (OLS) ကို အသုံးပြုပြီး Insertion Loss ကို တိုင်းတာနိုင်ပါတယ်။

ထို့အပြင် OTDR ကို အသုံးပြုပြီး Fiber Link တစ်လျှောက်မှာ ဖြစ်ပေါ်နေတဲ့ Events တွေ၊ Splice Loss နဲ့ အခြား Loss Events တွေကို ရှာဖွေနိုင်ပါတယ်။

🔬 Testing Tools

OLS → Optical Signal ပေးပို့
OPM → Optical Power တိုင်းတာ
OTDR → Fiber Event / Loss Location ရှာဖွေ

Total Fiber Link Loss

Fiber Link တစ်ခုရဲ့ Total Loss ဟာ Fiber Attenuation တစ်ခုတည်းနဲ့ မပြီးပါဘူး။

Fiber Loss အပြင် Connector Loss, Splice Loss နဲ့ အခြား Passive Component Loss တွေ ပါဝင်နိုင်ပါတယ်။

📐 အလွယ်မှတ်ရန်

Total Link Loss
= Fiber Loss + Connector Loss + Splice Loss + Component Loss

Attenuation များနေရင် ဘာလုပ်မလဲ?

  1. Connector တွေကို စစ်ဆေးပါ။
  2. Connector End Face ကို သန့်ရှင်းပါ။
  3. Patch Cord ကို စစ်ဆေးပါ။
  4. Fiber Cable မှာ Bend များနေသလား စစ်ဆေးပါ။
  5. Splice Point တွေကို စစ်ဆေးပါ။
  6. OPM / OLS အသုံးပြုပြီး Optical Loss ကို တိုင်းတာပါ။
  7. လိုအပ်ပါက OTDR နဲ့ Fiber Link ကို စစ်ဆေးပါ။

Quick Summary

Fiber Optic Attenuation ဆိုတာ Fiber Optic Link ထဲမှာ Light Signal Power လျော့နည်းသွားခြင်း ဖြစ်ပါတယ်။

Attenuation ဖြစ်စေတဲ့ အဓိကအကြောင်းရင်းတွေကတော့ Absorption, Rayleigh Scattering, Bending, Connector Loss နဲ့ Splice Loss တို့ ဖြစ်ပါတယ်။
