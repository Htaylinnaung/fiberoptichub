Mode Field Diameter (MFD)

Fiber Optic Basics • Intermediate • ⏱️ 3 min read
Published: 2026-08-30

Mode Field Diameter (MFD) ဆိုတာဘာလဲ?

Mode Field Diameter (MFD) ဆိုတာ Single Mode Fiber ထဲမှာ Light Mode ရဲ့ Effective Diameter (အလင်းဖြန့်ကျက်နေတဲ့ ထိရောက်သော အရွယ်အစား) ကို ဖော်ပြတဲ့ Parameter တစ်ခု ဖြစ်ပါတယ်။

MFD ကို Fiber ရဲ့ Physical Core Diameter (Core ရဲ့ တကယ့်အချင်း) နဲ့ တူတယ်လို့ မယူဆသင့်ပါဘူး။ MFD က Fiber Core အတွင်းမှာ Light Power ဘယ်လောက်အထိ ဖြန့်ကျက်နေသလဲဆိုတာနဲ့ ပိုမိုဆက်စပ်ပါတယ်။

💡 အလွယ်ဆုံးမှတ်ရန်

MFD = Fiber Core ထဲမှာ Light Mode ဖြန့်ကျက်နေတဲ့ Effective Size

MFD ≠ Physical Core Diameter

MFD ကို ဘာကြောင့်လေ့လာဖို့လိုသလဲ?

Single Mode Fiber မှာ Light ဟာ Core အတွင်းကနေ Mode တစ်ခုအနေနဲ့ ဖြတ်သန်းပါတယ်။ ဒါပေမယ့် Light Energy ဟာ Core အတွင်းမှာပဲ 100% ကန့်သတ်နေတယ်လို့ မဆိုနိုင်ပါဘူး။

Light Field ဟာ Cladding ဘက်ကိုလည်း အနည်းငယ် ဖြန့်ကျက်နိုင်ပါတယ်။ အဲဒီအတွက် Light Mode ရဲ့ Effective Size ကို နားလည်ဖို့ MFD က အရေးကြီးပါတယ်။

Core Diameter နဲ့ MFD ဘာကွာသလဲ?

Core Diameter ဆိုတာ Fiber ရဲ့ Physical Core ရဲ့ အချင်းကို ဆိုလိုပါတယ်။

Mode Field Diameter ကတော့ Fiber ထဲမှာ Propagating Light Mode (ဖြတ်သန်းသွားနေတဲ့ အလင်း Mode) ရဲ့ Effective Diameter ကို ဖော်ပြတာ ဖြစ်ပါတယ်။

Parameter အဓိပ္ပါယ်
Core Diameter Physical Core ရဲ့ အချင်း
Mode Field Diameter Light Mode ရဲ့ Effective Diameter
Measurement MFD ကို Optical Measurement နည်းလမ်းများဖြင့် သတ်မှတ်နိုင်သည်

Single Mode Fiber နဲ့ MFD

MFD ဆိုတဲ့ Concept ကို Single Mode Fiber (SMF) တွေမှာ အထူးသဖြင့် အသုံးများပါတယ်။

Single Mode Fiber ရဲ့ Core Diameter က သေးငယ်ပြီး Light ဟာ Fundamental Mode အနေနဲ့ ဖြတ်သန်းပါတယ်။ Light Field ရဲ့ အရွယ်အစားနဲ့ ဖြန့်ကျက်ပုံကို MFD နဲ့ ဖော်ပြနိုင်ပါတယ်။

📌 မှတ်ထားရန်

Single Mode Fiber မှာ

Physical Core = Fiber ရဲ့ တကယ့် Core

MFD = Light Mode ရဲ့ Effective Size

MFD နဲ့ Wavelength ဆက်နွယ်မှု

MFD ဟာ Fiber တစ်မျိုးတည်းအတွက်တောင် Wavelength (အလင်းလှိုင်းအလျား) ပြောင်းလဲသွားတဲ့အခါ ပြောင်းလဲနိုင်ပါတယ်။

အလင်းရဲ့ Wavelength နဲ့ Fiber ရဲ့ Optical Properties တွေကြောင့် Light Field ရဲ့ ဖြန့်ကျက်ပုံက ပြောင်းလဲနိုင်ပါတယ်။

ဒါကြောင့် MFD ကို ဖော်ပြတဲ့အခါ Wavelength နဲ့အတူ စဉ်းစားဖို့ လိုအပ်ပါတယ်။

MFD နဲ့ Fusion Splicing

Fiber နှစ်ချောင်းကို Fusion Splicing ပြုလုပ်တဲ့အခါ Fiber နှစ်ချောင်းရဲ့ Optical Characteristics မတူညီရင် Splice Loss ဖြစ်ပေါ်နိုင်ပါတယ်။

MFD မတူညီတဲ့ Fiber နှစ်ချောင်းကို ချိတ်ဆက်တဲ့အခါ Mode Field ရဲ့ မကိုက်ညီမှုကြောင့် Coupling Loss ဖြစ်နိုင်ပါတယ်။

တွေက Splice Performance အပေါ် သက်ရောက်မှုရှိနိုင်ပါတယ်။

MFD နဲ့ Connector / Coupling

Fiber Connector သို့မဟုတ် Optical Component တစ်ခုနဲ့ Fiber တစ်ချောင်းကို Coupling ပြုလုပ်တဲ့အခါ Light Field ရဲ့ အရွယ်အစားနဲ့ ပုံစံက အရေးကြီးပါတယ်။

MFD မကိုက်ညီမှုတွေရှိရင် Optical Power Transfer (အလင်းစွမ်းအား လွှဲပြောင်းမှု) ထိရောက်မှုကို ထိခိုက်စေနိုင်ပါတယ်။

MFD နဲ့ Bend Sensitivity

Fiber ရဲ့ MFD ဟာ Bend Sensitivity (Fiber ကွေးတဲ့အခါ Loss ဖြစ်လွယ်မှု) နဲ့လည်း ဆက်နွယ်မှုရှိနိုင်ပါတယ်။

Fiber ကို သတ်မှတ်ထားတဲ့ Bend Radius ထက် ပိုမိုကွေးထားရင် Optical Loss တိုးလာနိုင်ပါတယ်။

ဒါကြောင့် Fiber Design နဲ့ Network Installation တွေမှာ MFD နဲ့ Bend Performance တို့ရဲ့ ဆက်နွယ်မှုကို နားလည်ထားတာ အသုံးဝင်ပါတယ်။

MFD ရဲ့ တန်ဖိုးကို ဘယ်လိုဖော်ပြသလဲ?

MFD ကို ပုံမှန်အားဖြင့် Micrometer (µm) ယူနစ်နဲ့ ဖော်ပြပါတယ်။

ဥပမာအားဖြင့် Standard Single Mode Fiber တချို့မှာ Operating Wavelength ပေါ်မူတည်ပြီး MFD တန်ဖိုးက 9 µm ဝန်းကျင် ဖြစ်နိုင်ပါတယ်။

⚠️ အရေးကြီး

MFD တန်ဖိုးဟာ Fiber Type၊ Wavelength နဲ့ Manufacturer Specification ပေါ်မူတည်ပြီး ကွာခြားနိုင်ပါတယ်။

ဒါကြောင့် Fiber တစ်မျိုးရဲ့ MFD ကို သတ်မှတ်ဖို့ Datasheet / Specification ကို စစ်ဆေးသင့်ပါတယ်။

Fiber Network မှာ MFD ဘာကြောင့်အရေးကြီးသလဲ?

  • Splice Loss Fiber နှစ်ချောင်းချိတ်ဆက်ရာမှာ Optical Compatibility ကို နားလည်နိုင်ရန်
  • Coupling Optical Power ကို Fiber တစ်ချောင်းမှ တစ်ချောင်းသို့ ထိရောက်စွာ လွှဲပြောင်းနိုင်ရန်
  • Bend Performance Fiber ကွေးမှုနဲ့ Loss ဆက်နွယ်မှုကို နားလည်နိုင်ရန်
  • Fiber Design Fiber ရဲ့ Optical Characteristics တွေကို နားလည်နိုင်ရန်
