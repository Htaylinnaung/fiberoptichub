How Does an OTDR Work?

OTDR & OPM • Beginner • ⏱️ 3 min read
Published: 2026-08-28

OTDR ဆိုတာဘာလဲ?

OTDR (Optical Time Domain Reflectometer) ဆိုတာ Optical Fiber (အလင်းဖြင့် Data ပို့ဆောင်သော Fiber) ရဲ့ Link Condition (Fiber Link အခြေအနေ) ကို စစ်ဆေးတိုင်းတာဖို့ အသုံးပြုတဲ့ Fiber Testing Instrument (Fiber စမ်းသပ်တိုင်းတာသည့် ကိရိယာ) တစ်ခု ဖြစ်ပါတယ်။

OTDR ကို အသုံးပြုပြီး Fiber Link တစ်လျှောက်မှာရှိတဲ့ Distance (အကွာအဝေး)၊ Loss (Signal အားလျော့မှု)၊ Reflection (အလင်းပြန်မှု)၊ Splice Loss (Fiber ပေါင်းဆက်မှုကြောင့် ဖြစ်သော Loss) နဲ့ Fault Location (ချို့ယွင်းနေတဲ့နေရာ) တွေကို ရှာဖွေနိုင်ပါတယ်။

💡 အလွယ်ဆုံးမှတ်ရန်

OTDR = Fiber Link ကို အလင်း Pulse ပို့ပြီး ပြန်လာတဲ့ Signal ကို တိုင်းတာစစ်ဆေးတဲ့ Instrument

OTDR ဘယ်လိုအလုပ်လုပ်သလဲ?

OTDR က Optical Fiber ထဲကို Light Pulse (အလင်း Pulse) တစ်ခု ပို့လွှတ်ပါတယ်။

Light Pulse ဟာ Fiber ထဲကို ရှေ့ဆက်သွားနေတဲ့အချိန်မှာ Fiber ရဲ့ အတွင်းပိုင်းကနေ အလင်းအနည်းငယ် ပြန်လည်ဖြန့်ကျက်လာပါတယ်။ ဒီဖြစ်စဉ်ကို Backscattering (အလင်းပြန်လည်ဖြန့်ကျက်မှု) လို့ ခေါ်ပါတယ်။

Fiber ထဲမှာ Connector (ချိတ်ဆက်ကိရိယာ)၊ Splice (Fiber ပေါင်းဆက်နေရာ)၊ Bend (Fiber ကွေးနေရာ) သို့မဟုတ် Break (Fiber ပြတ်နေရာ) စတဲ့ Event တွေရှိရင် ပြန်လာတဲ့ Signal ပုံစံက ပြောင်းလဲသွားနိုင်ပါတယ်။

OTDR က ပြန်လာတဲ့ Signal ရဲ့ Time (အချိန်) နဲ့ Power Level (Signal အင်အား) ကို တိုင်းတာပြီး Fiber Link တစ်လျှောက်မှာ ဘာဖြစ်နေတယ်ဆိုတာကို Trace (တိုင်းတာမှုဂရပ်) အနေနဲ့ ပြသပေးပါတယ်။

OTDR ရဲ့ အခြေခံ Principle

Light Pulse

↓

Fiber ထဲသို့ ပို့လွှတ်ခြင်း

↓

Backscattered / Reflected Signal

↓

OTDR က ပြန်လည်တိုင်းတာခြင်း

↓

Distance + Loss + Events + Fault Location

OTDR က ဘာတွေကို တိုင်းတာနိုင်သလဲ?

  • Fiber Distance (Fiber အကွာအဝေး)
  • Fiber Loss (Fiber တစ်လျှောက် Signal အားလျော့မှု)
  • Splice Loss (Splice ကြောင့် ဖြစ်သော Loss)
  • Connector Loss (Connector ကြောင့် ဖြစ်သော Loss)
  • Reflection (အလင်းပြန်မှု)
  • Fiber Break (Fiber ပြတ်နေရာ)
  • High Loss Event (Loss များပြားနေသောနေရာ)
  • Fault Location (ချို့ယွင်းနေသောနေရာ)

OTDR Trace ဆိုတာဘာလဲ?

OTDR က တိုင်းတာပြီးရရှိတဲ့ Result ကို OTDR Trace (တိုင်းတာမှုဂရပ်) အဖြစ် Screen ပေါ်မှာ ပြသပေးပါတယ်။

Trace ရဲ့ Horizontal Axis (အလျားလိုက် Axis) မှာ Distance (အကွာအဝေး) ကို ပြသပြီး Vertical Axis (ဒေါင်လိုက် Axis) မှာ Optical Power (အလင်း Signal အင်အား) ကို ပြသလေ့ရှိပါတယ်။

Fiber တစ်လျှောက်မှာ Loss ဖြစ်တဲ့နေရာ၊ Reflection ဖြစ်တဲ့နေရာနဲ့ Fiber End (Fiber အဆုံး) စတဲ့ Event တွေကို Trace ပေါ်မှာ ခွဲခြားမြင်နိုင်ပါတယ်။

OTDR မှာတွေ့ရနိုင်တဲ့ Events

Event အဓိပ္ပါယ်
Connector Fiber Connector ချိတ်ဆက်ထားသောနေရာ
Splice Fiber နှစ်ချောင်း ပေါင်းဆက်ထားသောနေရာ
Bend Fiber ကွေးမှုကြောင့် Loss ဖြစ်နိုင်သောနေရာ
Reflection Light Signal ပြန်လည်ရောင်ပြန်သောနေရာ
Fiber End Fiber Link အဆုံးနေရာ
Break Fiber ပြတ်နေသောနေရာ

OTDR Dead Zone ဆိုတာဘာလဲ?

OTDR မှာ Dead Zone (တိုင်းတာမှု မတိကျနိုင်သော အကွာအဝေး) ဆိုတဲ့ အရေးကြီးတဲ့ Concept (အခြေခံသဘောတရား) တစ်ခု ရှိပါတယ်။

OTDR က အလွန်နီးကပ်တဲ့ Event တွေကို ခွဲခြားဖော်ထုတ်ရာမှာ အခက်အခဲရှိနိုင်တဲ့ အကွာအဝေးကို Dead Zone လို့ ခေါ်ပါတယ်။

📌 မှတ်ထားရန်

Dead Zone ဟာ OTDR Testing (OTDR ဖြင့် စမ်းသပ်တိုင်းတာခြင်း) မှာ အရေးကြီးတဲ့ အကြောင်းအရာတစ်ခု ဖြစ်ပါတယ်။

OTDR Test Parameters

OTDR Test မလုပ်ခင် သင့်တော်တဲ့ Parameters (တိုင်းတာမှု သတ်မှတ်ချက်များ) တွေကို ရွေးချယ်ဖို့ လိုအပ်ပါတယ်။

  • Wavelength (အလင်းလှိုင်းအလျား)
  • Range (တိုင်းတာမည့် အကွာအဝေး)
  • Pulse Width (Light Pulse အကျယ်/ကြာချိန်)
  • Averaging Time (Signal တိုင်းတာမှု ပျမ်းမျှတွက်သည့်အချိန်)

Wavelength ကို ဘာကြောင့်ရွေးရသလဲ?

OTDR တွေမှာ 1310 nm၊ 1550 nm စတဲ့ Wavelength တွေကို အသုံးပြုနိုင်ပါတယ်။

Wavelength မတူတဲ့အခါ Fiber ရဲ့ Attenuation (Signal အားလျော့မှု) နဲ့ Bend Sensitivity (ကွေးမှုအပေါ် သက်ရောက်မှု) တွေလည်း ကွာခြားနိုင်ပါတယ်။

Pulse Width ဆိုတာဘာလဲ?

Pulse Width (Light Pulse ကြာချိန်) ဆိုတာ OTDR က Fiber ထဲကို ပို့လွှတ်တဲ့ Light Pulse ရဲ့ ကြာချိန်ကို ဆိုလိုပါတယ်။

Short Pulse ကို အသုံးပြုရင် အနီးကပ် Event တွေကို ပိုကောင်းစွာ ခွဲခြားနိုင်ပေမယ့် Long Distance အတွက် Signal Level နိမ့်နိုင်ပါတယ်။

Long Pulse ကို အသုံးပြုရင် Long Distance Measurement အတွက် အထောက်အကူဖြစ်နိုင်ပေမယ့် Resolution လျော့နည်းနိုင်ပါတယ်။

OTDR ကို ဘာကြောင့်အသုံးပြုတာလဲ?

Fiber Link တစ်ခုမှာ Problem ဖြစ်လာတဲ့အခါ Fiber အတွင်း ဘယ်နေရာမှာ ဖြစ်နေတယ်ဆိုတာကို ရှာဖွေနိုင်ဖို့ OTDR က အလွန်အသုံးဝင်ပါတယ်။

  • Fiber Installation Verification (တပ်ဆင်ပြီးနောက် Fiber အခြေအနေစစ်ဆေးခြင်း)
  • Fiber Maintenance (Fiber ပြုပြင်ထိန်းသိမ်းခြင်း)
  • Fault Finding (ချို့ယွင်းနေရာရှာဖွေခြင်း)
  • Splice Verification (Splice အရည်အသွေးစစ်ဆေးခြင်း)
  • Fiber Link Troubleshooting (Fiber Link ပြဿနာရှာဖွေဖြေရှင်းခြင်း)
⚠️ အရေးကြီးသောအချက်

OTDR တိုင်းတာမှုမလုပ်ခင် Fiber Connector တွေကို သန့်ရှင်းထားဖို့ အရေးကြီးပါတယ်။

Dirty Connector ကြောင့် Loss နဲ့ Reflection Result တွေ မှားယွင်းနိုင်ပါတယ်။

Quick Summary

OTDR (Optical Time Domain Reflectometer) ဆိုတာ Optical Fiber Link ကို စမ်းသပ်တိုင်းတာပြီး Fiber ရဲ့ အခြေအနေကို ခွဲခြမ်းစိတ်ဖြာနိုင်တဲ့ Testing Instrument တစ်ခု ဖြစ်ပါတယ်။

OTDR က Fiber ထဲကို Light Pulse ပို့ပြီး ပြန်လာတဲ့ Backscattered နဲ့ Reflected Signal တွေကို တိုင်းတာပါတယ်။

အဲဒီ Result ကို အသုံးပြုပြီး Distance၊ Loss၊ Reflection၊ Splice နဲ့ Fault Location စတဲ့ အချက်တွေကို ရှာဖွေနိုင်ပါတယ်။
