Fiber Optic Loss

Fiber Optic Basics • Beginner • ⏱️ 2 min read
Published: 2026-08-30

Fiber Optic Loss ဆိုတာဘာလဲ?

Fiber Optic Loss ဆိုတာ Optical Fiber ထဲမှာ Light Signal ဖြတ်သန်းသွားတဲ့အခါ Optical Power လျော့နည်းသွားခြင်းကို ဆိုလိုပါတယ်။

Fiber Link တစ်ခုမှာ Transmitter ကနေ Receiver ဆီကို Light Signal ပို့တဲ့အခါ လမ်းတစ်လျှောက်မှာ Optical Power အချို့ လျော့နည်းသွားနိုင်ပါတယ်။

Fiber Loss ကို ဘာနဲ့တိုင်းတာသလဲ?

Fiber Optic Loss ကို ပုံမှန်အားဖြင့် Decibel (dB) နဲ့ ဖော်ပြပါတယ်။

Fiber တစ်ကီလိုမီတာအတွင်း Signal ဘယ်လောက်လျော့နည်းသလဲဆိုတာကို dB/km နဲ့ ဖော်ပြနိုင်ပါတယ်။

Term အဓိပ္ပါယ်
dB Optical Power Loss ကို ဖော်ပြရန် အသုံးပြုသော Unit
dB/km Fiber တစ်ကီလိုမီတာအလိုက် Loss
Optical Power Light Signal ရဲ့ အလင်းစွမ်းအား

Fiber Loss ဖြစ်စေတဲ့ အဓိကအကြောင်းရင်းများ

Fiber Link တစ်ခုမှာ Loss ဖြစ်စေတဲ့ အကြောင်းရင်းများစွာရှိပါတယ်။

  • Absorption Loss
    Fiber Material ထဲမှာ Light Energy အချို့ စုပ်ယူခံရခြင်းကြောင့် ဖြစ်ပေါ်နိုင်ပါတယ်။
  • Scattering Loss
    Fiber Glass ရဲ့ Microscopic Structure ကြောင့် Light အချို့ ပြန့်ကျဲသွားခြင်းကြောင့် ဖြစ်နိုင်ပါတယ်။
  • Bending Loss
    Fiber ကို သတ်မှတ်ထားတဲ့ Bend Radius ထက် ပိုကွေးထားတဲ့အခါ Loss တိုးလာနိုင်ပါတယ်။
  • Connector Loss
    Connector နှစ်ခုချိတ်ဆက်ရာမှာ Alignment မပြည့်စုံခြင်း၊ Dirt သို့မဟုတ် Physical Damage ရှိခြင်းတို့ကြောင့် Loss ဖြစ်နိုင်ပါတယ်။
  • Splice Loss
    Fiber နှစ်ချောင်းကို Fusion Splicing သို့မဟုတ် Mechanical Splicing ပြုလုပ်ရာမှာ Alignment မမှန်ကန်မှုများကြောင့် Loss ဖြစ်နိုင်ပါတယ်။

Bending Loss ဆိုတာဘာလဲ?

Fiber ကို အလွန်အမင်းကွေးထားတဲ့အခါ Light Signal အချို့ဟာ Core ထဲမှာ မထိန်းနိုင်တော့ဘဲ အပြင်ဘက်ကို ထွက်သွားနိုင်ပါတယ်။

ဒါကြောင့် Fiber Installation ပြုလုပ်တဲ့အခါ Manufacturer သတ်မှတ်ထားတဲ့ Minimum Bend Radius ကို လိုက်နာဖို့ အရေးကြီးပါတယ်။

Installation မှာ သတ်မှတ်ထားတဲ့ Bend Radius ကို လိုက်နာပါ။

Connector နဲ့ Splice Loss

Fiber Link တစ်ခုမှာ Connector နဲ့ Splice တွေ များလာလေလေ Total Loss တိုးလာနိုင်ပါတယ်။

Connector End Face တွေမှာ Dust၊ Dirt သို့မဟုတ် Scratch တွေရှိနေရင် Optical Power Transmission ထိခိုက်နိုင်ပါတယ်။

ဒါကြောင့် Fiber Connector Inspection နဲ့ Cleaning ဟာ Fiber Network Maintenance မှာ အရေးကြီးပါတယ်။

Total Link Loss

Fiber Link တစ်ခုရဲ့ Total Loss ကို Fiber Loss တစ်ခုတည်းနဲ့ မသတ်မှတ်ပါဘူး။

Fiber Length၊ Connector Loss၊ Splice Loss နဲ့ အခြား Passive Components တွေရဲ့ Loss တွေကို စုပေါင်းစဉ်းစားရပါတယ်။

Fiber Loss ကို ဘယ်လိုစမ်းသပ်မလဲ?

Fiber Link Loss ကို Optical Power Meter နဲ့ Light Source အသုံးပြုပြီး တိုင်းတာနိုင်ပါတယ်။

OTDR ကိုလည်း Fiber Link အတွင်းက Loss Event၊ Splice၊ Connector နဲ့ Reflection စတဲ့ Event တွေကို ရှာဖွေစစ်ဆေးရာမှာ အသုံးပြုနိုင်ပါတယ်။

Tool အသုံးပြုမှု

Quick Summary

Fiber Optic Loss ဆိုတာ Fiber Link ထဲမှာ Optical Power လျော့နည်းသွားခြင်း ဖြစ်ပါတယ်။

Fiber Loss ကို dB နဲ့ ဖော်ပြနိုင်ပြီး Fiber Length၊ Bending၊ Splice၊ Connector နဲ့ Fiber Material တို့က Loss အပေါ် သက်ရောက်နိုင်ပါတယ်။

Fiber Link တစ်ခုကို မှန်ကန်စွာ Installation ပြုလုပ်ပြီး Optical Power Meter၊ Light Source နဲ့ OTDR တို့ကို သင့်တော်သလို အသုံးပြုခြင်းအားဖြင့် Fiber Performance ကို စစ်ဆေးနိုင်ပါတယ်။
