Fiber Optic Color Codes (TIA/EIA-598 Standard)

Fiber Optic Basics • Beginner • ⏱️ 3 min read
Published: 2026-09-03

၁။ နိဒါန်း

Fiber Optic Communication Network များတွင် Cable များ အတွင်းရှိ အမျှင် (Core) ပေါင်း ရာထောင်ချီကို တိကျစွာ ခွဲခြားဆက်သွယ်နိုင်ရန်နှင့် Fusion Splicing ပြုလုပ်ရာတွင် လွဲမှားမှု မရှိစေရန်အတွက် Standard Color Code စနစ်ကို အသုံးပြုကြပါသည်။ အပြည်ပြည်ဆိုင်ရာ စံနှုန်းဖြစ်သော TIA/EIA-598 Standard သည် Fiber Optic Cables များ၏ Cores၊ Buffer Tubes၊ Outer Jackets နှင့် Connectors/Boot Color များကို ခွဲခြားသတ်မှတ်ပေးထားသည့် အဓိက Standard ဖြစ်ပါသည်။

၂။ Standard 12 Color Sequence နှင့် Cable Types

  • The 12-Color Sequence: Fiber Optic Cores နှင့် Buffer Tubes များကို စတင်ရေတွက်ရာတွင် Standard အရောင် ၁၂ မျိုး အစဉ်လိုက်အတိုင်း သတ်မှတ်ထားပါသည် - 1-Blue, 2-Orange, 3-Green, 4-Brown, 5-Slate (Grey), 6-White, 7-Red, 8-Black, 9-Yellow, 10-Violet (Purple), 11-Rose (Pink), 12-Aqua (Turquoise)။
  • Multi-Core Cable Identification (Above 12 Cores): Fiber Core ၁၂ ခုထက် ပိုမိုသော Cables (ဥပမာ - 24 Core, 48 Core, 96 Core, 144 Core) များတွင် ၎င်း ၁၂ ရောင် အစဉ်လိုက်အတိုင်း Buffer Tubes များကို အရင်ခွဲခြားပြီး Tube တစ်ခုစီ၏ အတွင်း၌ Core ၁၂ ခုစီကို အရောင်စဉ်အတိုင်း ပြန်လည် ထည့်သွင်းထားပါသည်။ ဥပမာ - Orange Tube (Tube No. 2) အတွင်းရှိ Blue Core သည် Fiber No. 13 ဖြစ်ပါသည်။
  • Outer Jacket Color Codes: Patch Cords သို့မဟုတ် Indoor Cables များ၏ အပြင်ဘက် Jacket အရောင်ကို ကြည့်ခြင်းဖြင့် Fiber Type ကို လွယ်ကူစွာ ခွဲခြားနိုင်ပါသည် -
    • Yellow: Single-mode Fiber (OS1 / OS2, 9/125 µm)
    • Orange: Multimode Fiber (OM1 - 62.5/125 µm / OM2 - 50/125 µm)
    • Aqua: Laser-Optimized Multimode Fiber (OM3 / OM4 - 50/125 µm)
    • Erika Violet: Multimode Fiber (OM5 - Wideband Multimode)

၃။ Fiber Cable Spec & Color Code Quick Reference

Fiber No. / Type Color Name (Core / Tube) Jacket Color (Patch Cord) Connector Polish Color
1 / 13 / 25 ... Blue Yellow (Single-mode) Blue (UPC)
2 / 14 / 26 ... Orange Orange (OM1/OM2) Green (APC)
3 / 15 / 27 ... Green Aqua (OM3/OM4) Black / Beige (Multimode)
4 / 16 / 28 ... Brown Erika Violet (OM5) -
💡 Field Rule (Splicing Warning): Fusion Splicing ပြုလုပ်ချိန်တွင် Tube 1 (Blue) ၏ Core 1 (Blue) ကို အခြားဘက် Cable ၏ Tube 1 (Blue) ၏ Core 1 (Blue) နှင့်သာ Straight Splicing ပြုလုပ်ရမည် ဖြစ်ပါသည်။ Color Mismatch ဖြစ်ပါက Network Mapping မှားယွင်းသွားပြီး Signal Continuity ပျက်စီးနိုင်ပါသည်။

၄။ Field Maintenance & Troubleshooting Best Practices

  • Visual Inspection: Outdoor Ribbon Cable သို့မဟုတ် Loose Tube Cable များကို လှီးဖြတ်ရာတွင် Binder Threads သို့မဟုတ် Color Stripe တင်းကြပ်စွာ ပါဝင်မှုရှိမရှိ စစ်ဆေးပါ။
  • Black Core Identification: Core No. 8 (Black Core) ကို Splice Tray တွင် ကြည့်ရှုစဉ် အမှောင်ထဲ၌ မှားယွင်းနိုင်သဖြင့် Color Identification Tape သို့မဟုတ် VFL (Visual Fault Locator) ဖြင့် အလင်းလွှတ်၍ သေချာစွာ စစ်ဆေးပါ။
  • Connector Cleaning: Color Code ဖြင့် Connector အမျိုးအစား (UPC-Blue vs APC-Green) ခွဲခြားပြီးသည်နှင့် ချိတ်ဆက်ခြင်း မပြုမီ One-click Cleaner Pen သို့မဟုတ် Lint-free Wipes ဖြင့် အမြဲမပြတ် သန့်ရှင်းရေး ပြုလုပ်ပေးပါ။
