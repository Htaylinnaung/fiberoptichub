Fiber Optic Color Code Standard (TIA/EIA-598)

Fiber Optic Basics • Beginner • ⏱️ 3 min read
Published: 2026-09-02

Fiber Optic Color Code ဆိုတာဘာလဲ?

ဖိုက်ဘာ အလင်းမျှင် ကေဘယ်ကြိုး (Fiber Optic Cable) တစ်ခု၏ အတွင်းပိုင်းတွင် ဖိုက်ဘာ ကြိုးမျှင် (Fiber Cores) ပမာဏ များစွာ ပါဝင်လေ့ ရှိပါသည်။ ကေဘယ်ကြိုး စက်ရုံ ထုတ်လုပ်မှုနှင့် အကွက်ချ တပ်ဆင်ဆက်သွယ်သည့် အခါတွင် ကြိုးမျှင် တစ်ခုချင်းစီကို တိကျစွာ ခွဲခြား စေရန်အတွက် TIA/EIA-598 Color Code Standard စနစ်ကို အသုံးပြုကြပါသည်။

ဤ စံနှုန်းစနစ်သည် ဖိုက်ဘာ အမျှင်များ (Cores) နှင့် အကာအကွယ် ဗူးချောင်းများ (Buffer Tubes) ၏ အရောင် အစဉ်လိုက် စည်းမျဉ်းကို သတ်မှတ် ပေးထားခြင်း ဖြစ်ပါသည်။ ယင်း အရောင် စည်းမျဉ်းကြောင့် အင်ဂျင်နီယာများ နှင့် နည်းပညာရှင်များ အနေဖြင့် မည်သည့် ကြိုးမျှင်ကို မည်သည့် လမ်းကြောင်းသို့ အမျှင်ဆက်ခြင်း (Fusion Splicing) ပြုလုပ် ရမည်နည်း ဆိုသည်ကို အမှားအယွင်း မရှိ မြန်ဆန်စွာ ခွဲခြား သိရှိနိုင်ပါသည်။

💡 အလွယ်ဆုံးမှတ်ရန်:

Fiber Optic Color Code ဆိုသည်မှာ ကေဘယ်ကြိုး အတွင်းမှ Fiber Core တစ်ခုချင်းစီ နှင့် Buffer Tube များ၏ အစဉ်လိုက် အရောင် သတ်မှတ်ချက် (TIA/EIA-598 Standard) ဖြစ်ပါသည်။

Color Code ဘယ်လိုအလုပ်လုပ်သလဲ?

Fiber Optic Network တည်ဆောက်ရာတွင် ကေဘယ်ကြိုး အတွင်းရှိ Core များ အားလုံးသည် အရောင်တူ စနစ်ဖြင့် တည်ရှိနေပါက မည်သည့် အမျှင်ကို ဆက်ရမည်ကို ခွဲခြားရ ခက်ခဲစေမည် ဖြစ်ပါသည်။ Color Coding စနစ်သည် အောက်ပါ စည်းမျဉ်း အဆင့်လိုက် အလုပ်လုပ်ပါသည် -

  • Core Level Identification: 1 Core မှ 12 Core အထိ အခြေခံ အရောင် ၁၂ ရောင်ကို တိကျသည့် အစဉ်လိုက်အတိုင်း အသုံးပြုထားပါသည်။
  • Buffer Tube Level Identification: Core အရေအတွက် ၁၂ ထက် ပိုမိုများပြားပါက Tube တစ်ခုချင်းစီကိုလည်း အဆိုပါ အရောင် ၁၂ ရောင် အစဉ်လိုက်အတိုင်း ထပ်မံ ခွဲခြားထားပါသည်။
  • Multi-Fiber Sequence: ဥပမာ - Blue Tube အတွင်းရှိ Blue Core သည် Fiber No. 1 ဖြစ်ပြီး၊ Orange Tube အတွင်းရှိ Blue Core သည် Fiber No. 13 ဖြစ်လာပါမည်။

အဓိက Core အရောင် ၁၂ ရောင် အစဉ်လိုက် (12-Color Sequence)

TIA/EIA-598 Standard အရ အသုံးပြုသည့် Fiber Core အရောင် ၁၂ ရောင်၏ အော်ဒါ အစဉ်လိုက်မှာ အောက်ပါအတိုင်း ဖြစ်ပါသည် -

  1. Blue (ပြာ) - Core 1
  2. Orange (လိမ္မော်) - Core 2
  3. Green (စိမ်း) - Core 3
  4. Brown (ညို) - Core 4
  5. Slate / Grey (မီးခိုး) - Core 5
  6. White (ဖြူ) - Core 6
  7. Red (နီ) - Core 7
  8. Black (နက်) - Core 8
  9. Yellow (ဝါ) - Core 9
  10. Violet / Purple (ခရမ်း) - Core 10
  11. Rose / Pink (ပန်း) - Core 11
  12. Aqua / Turquoise (အပြာနု) - Core 12

Technical Specifications & Color Code Reference Table

ကေဘယ်ကြိုး အရေအတွက် ခွဲခြားမှုနှင့် Outer Jacket အရောင် သတ်မှတ်ချက်များကို အောက်ပါ Reference Table တွင် လေ့လာနိုင်ပါသည်။

Fiber No. Core Color Buffer Tube Color Jacket Color (Cable Type)
1 - 12 12 Standard Colors Sequence Tube 1: Blue Yellow (Single-Mode Fiber)
13 - 24 12 Standard Colors Sequence Tube 2: Orange Aqua (Multimode OM3/OM4)
25 - 36 12 Standard Colors Sequence Tube 3: Green Orange (Multimode OM1/OM2)
37 - 48 12 Standard Colors Sequence Tube 4: Brown Erika Violet (Multimode OM5)

Color Code Standard ၏ အဓိက Function များနှင့် အားသာချက်များ

စံသတ်မှတ်ထားသော အရောင်စနစ်များ သုံးစွဲခြင်းဖြင့် အောက်ပါ အကျိုးကျေးဇူးများကို ရရှိစေပါသည် -

  • Splicing Error လျှော့ချနိုင်ခြင်း: Splicer Engineer များ အနေဖြင့် Core တစ်ခုချင်းစီကို တိကျစွာ ချိတ်ဆက်နိုင်ပြီး ခွဲခြားရ ခက်ခဲမှုနှင့် မှားယွင်းမှု မရှိစေပါ။
  • Troubleshooting မြန်ဆန်ခြင်း: Cable Fault သို့မဟုတ် Fiber Break ဖြစ်ပေါ်ပါက ပြဿနာဖြစ်သည့် Core အရောင်ကို လျင်မြန်စွာ စစ်ဆေး ပြင်ဆင်နိုင်ပါသည်။
  • Standardization တိုးတက်ခြင်း: ကမ္ဘာတစ်ဝှမ်းရှိ Fiber Optic Network အဖွဲ့အစည်းများ အချင်းချင်း စံနှုန်းတစ်ခုတည်းဖြင့် တည်ဆောက် ထိန်းသိမ်းနိုင်ပါသည်။

Quick Summary

Fiber Optic Color Code Standard (TIA/EIA-598) သည် Fiber Network စနစ်တစ်ခုလုံး၏ အရေးပါသော စံနှုန်း တစ်ခု ဖြစ်ပါသည်။ အခြေခံ ၁၂ ရောင် စနစ် (Blue, Orange, Green, Brown, Slate, White, Red, Black, Yellow, Violet, Rose, Aqua) ကို စနစ်တကျ မှတ်သားထားခြင်းဖြင့် Fusion Splicing နှင့် Field Testing လုပ်ငန်းစဉ်များကို အမှားအယွင်းမရှိ ထိရောက်စွာ ဆောင်ရွက်နိုင်မည် ဖြစ်ပါသည်။

🎯 နောက်တစ်ဆင့်:

Color Code ခွဲခြားနည်းကို လေ့လာပြီးနောက် Fiber Core များကို အလင်းယိုစီးမှု နည်းပါးစွာ ဆက်သွယ်နည်း လေ့လာရန် Fusion Splicing Basics ဆောင်းပါးသို့ ဆက်လက်လေ့လာနိုင်ပါသည်။
