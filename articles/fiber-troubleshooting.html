Fiber Troubleshooting

Fiber Optic Basics • Beginner • ⏱️ 2 min read
Published: 2026-08-29

Fiber Troubleshooting ဆိုတာဘာလဲ?

Fiber Troubleshooting ဆိုတာ Fiber Optic Network မှာ ဖြစ်ပေါ်နေတဲ့ ပြဿနာတွေကို ရှာဖွေဖော်ထုတ်ပြီး ပြဿနာရဲ့ အကြောင်းရင်းကို သိရှိကာ မှန်ကန်တဲ့နည်းလမ်းနဲ့ ဖြေရှင်းခြင်း ဖြစ်ပါတယ်။

Fiber Link တစ်ခုမှာ Link Down ဖြစ်ခြင်း၊ Optical Power နည်းခြင်း၊ High Loss ဖြစ်ခြင်း၊ Fiber Break ဖြစ်ခြင်း၊ Connector ညစ်ပတ်ခြင်းနဲ့ Splice Quality မကောင်းခြင်း စတဲ့ ပြဿနာတွေ ဖြစ်နိုင်ပါတယ်။

💡 အလွယ်ဆုံးမှတ်ရန်

Fiber Troubleshooting =

Problem ရှာ → Cause ရှာ → ပြင် → ပြန်စမ်း

Fiber Optic Network မှာ ဖြစ်တတ်တဲ့ ပြဿနာများ

  • Link Down
  • Low Optical Power
  • High Optical Loss
  • Fiber Break
  • Dirty Connector
  • Damaged Patch Cord
  • Poor Fusion Splice
  • Excessive Fiber Bend

1. Physical Inspection

Troubleshooting ပြုလုပ်တဲ့အခါ ပထမဆုံးအနေနဲ့ Fiber Cable နဲ့ Network Equipment တွေကို မျက်မြင်စစ်ဆေးသင့်ပါတယ်။

Patch Cord လွတ်နေခြင်း၊ Connector မတပ်ထားခြင်း၊ Cable ပျက်စီးခြင်း၊ Fiber အလွန်အကျွံကွေးနေခြင်း ရှိမရှိ စစ်ဆေးပါ။

2. Connector ကို စစ်ဆေးခြင်း

Fiber Connector ရဲ့ End Face မှာ Dust၊ Dirt နဲ့ အခြားအညစ်အကြေးတွေ ရှိနေပါက Optical Loss တိုးလာနိုင်ပါတယ်။

ဒါကြောင့် Connector ကို သင့်တော်တဲ့ Fiber Cleaning Tool အသုံးပြုပြီး သန့်ရှင်းအောင် ပြုလုပ်ပြီးနောက် ပြန်လည်စမ်းသပ်သင့်ပါတယ်။

3. Optical Power ကို တိုင်းတာခြင်း

Optical Power Meter (OPM) ကို အသုံးပြုပြီး Fiber Link ရဲ့ Receive Optical Power ကို တိုင်းတာနိုင်ပါတယ်။

Optical Power က သတ်မှတ်ထားတဲ့ Normal Level ထက် အလွန်နည်းနေပါက Fiber Link အတွင်းမှာ Loss ဖြစ်နေတဲ့နေရာတစ်ခုခု ရှိနိုင်ပါတယ်။

📌 သတိပြုရန်

Optical Power တစ်ခုတည်းကိုကြည့်ပြီး Fault Location ကို တိတိကျကျ မသတ်မှတ်နိုင်ပါ။

Fault Location ရှာဖို့ OTDR လို Testing Equipment ကို အသုံးပြုနိုင်ပါတယ်။

4. OTDR အသုံးပြုပြီး Fault ရှာခြင်း

OTDR (Optical Time Domain Reflectometer) ဟာ Fiber Link တစ်လျှောက်မှာ ဖြစ်ပေါ်နေတဲ့ Event တွေကို ရှာဖွေဖော်ထုတ်ဖို့ အသုံးပြုတဲ့ Testing Instrument တစ်ခု ဖြစ်ပါတယ်။

OTDR နဲ့ Connector၊ Fusion Splice၊ Fiber Bend၊ Reflection Event နဲ့ Fiber Break စတဲ့ Event တွေကို စစ်ဆေးနိုင်ပါတယ်။

5. Fusion Splice ကို စစ်ဆေးခြင်း

Fiber Link မှာ Fusion Splice ပြုလုပ်ထားရင် Splice Point တစ်ခုချင်းစီရဲ့ Quality ကို စစ်ဆေးဖို့ လိုအပ်ပါတယ်။

Splice Quality မကောင်းပါက Splice Loss မြင့်လာပြီး Fiber Link ရဲ့ Total Loss ကို တိုးစေနိုင်ပါတယ်။

6. Fiber Bend ကို စစ်ဆေးခြင်း

Fiber Cable ကို သတ်မှတ်ထားတဲ့ Minimum Bend Radius ထက် ပိုမိုကွေးထားပါက Optical Loss တိုးလာနိုင်ပါတယ်။

ဒါကြောင့် Fiber Installation နဲ့ Maintenance ပြုလုပ်တဲ့အခါ Fiber Cable ကို အလွန်အကျွံမကွေးအောင် သတိထားရပါတယ်။

🔧 Recommended Troubleshooting Flow

  1. Physical Inspection
  2. Check Connector
  3. Clean Connector
  4. Check Patch Cord
  5. Measure Optical Power
  6. Check Splice
  7. Perform OTDR Test
  8. Locate the Fault
  9. Repair the Fault
  10. Retest the Fiber Link

Fiber Loss ဖြစ်စေတဲ့ အဓိကအကြောင်းရင်းများ

Problem ဖြစ်နိုင်တဲ့အကြောင်းရင်း
High Loss Dirty Connector / Poor Splice / Bend
Link Down Fiber Break / Loose Connection
Low Optical Power High Loss / Damaged Fiber
High Reflection Connector Problem / Poor Termination
📌 Important

Troubleshooting လုပ်တဲ့အခါ ပြဿနာကို ခန့်မှန်းပြီး တန်းပြင်တာထက် အဆင့်လိုက် စစ်ဆေးပြီး Fault Cause ကို ရှာဖွေတာ ပိုအရေးကြီးပါတယ်။
